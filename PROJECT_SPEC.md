# EVE Healthcare SDE Intern Assignment

## Objective

Build a backend service for diagnostic test bookings and simulated payments.

## Required

- User signup
- User login
- JWT authentication
- Request validation
- Diagnostic centres
- Diagnostic tests
- Test prices
- Booking creation
- Appointment date/time
- Booking status
- Simulated payment
- Payment success/failure
- Payment webhook
- Idempotent webhook processing
- Authorization
- Invalid request handling
- Invalid booking handling
- Failed payment handling

## Bonus

- Docker
- PostgreSQL
- Swagger/OpenAPI
- Unit tests
- Integration tests
- Structured logging
- Pagination
- Rate limiting
- Retry handling

## Important

Engineering quality is more important than feature count.
